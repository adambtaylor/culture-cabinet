## Transport boundary

`transport_planning.py` is pure computation. It uses an explicit Melbourne planning timezone, DST validation and user estimates for departure/return buffers. It does not infer a show finish, overnight return day, home location, nearest station, bike space, weather, last train, disruption, fare or route safety. The station comparison accepts separate cycling and onward estimates for Batman, Coburg and Merlynston, ranks only complete entries with an explanation, exposes ties/incomplete comparisons, and leaves the chosen station unchanged. Leaving bikes requires returning to that exact parking station. Onward estimates must include waits, transfers and the final venue leg; no routing result is invented.

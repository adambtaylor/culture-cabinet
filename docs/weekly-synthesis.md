# Bounded weekly synthesis review

The existing private runtime owns one internal clock thread. It checks at most once per minute and can queue a review receipt; it has no inference client and performs no model or provider calls. No external automation, cron entry, service, credential or new paid provider is created.

The calendar anchor is **Monday 08:00 Australia/Melbourne**. The first due slot is **2 November 2026 at 08:00 AEDT**, or **1 November at 21:00 UTC**. The existing runtime ends **6 November 2026 at 04:17:29 UTC / 15:17:29 AEDT**. The next Monday, 9 November, is outside that window and cannot enqueue. Nothing renews or extends the runtime. A stopped runtime does not run the trigger; restart uses the same durable cursor rather than moving the calendar anchor.

At the due slot, the service rechecks the actual deployed process/session metadata, fixed expiry/renewal, active owner and profile grant. It snapshots only current persisted signals through the existing synthesis service. Staged art and dossier packets are not inputs. The fixed private cursor binds the captured slot and digest before database creation, so a crash reconciles that exact reservation. One owned file lock and the existing actor/profile/input-digest constraint prevent duplicate jobs. Completed, failed, unknown and running jobs with unchanged input are reused without resetting attempts or executing inference. No catch-up storm or post-expiry enqueue is permitted.

A new row is a **pending-review** SynthesisRun with zero inference attempts. It is not an Astra result. The current authenticated Synergize form must explicitly approve that unchanged snapshot before the existing trusted operator may reserve a supervised task. A later taste edit makes the old snapshot historical. Missing owner browser authentication still blocks this review and personal observation imports; it does not justify a synthetic session or raw database write. The scheduled adapter uses its separately authorized internal runtime authority, not a forged HTTP request.

The configured supervised route remains `gpt-6-astra` with `high` reasoning through Codex collaboration. Automatic model-call cap: **0**. Automatic provider-call cap: **0**. At most one weekly slot falls within this approved runtime. Existing database constraints retain a maximum of one inference reservation per input job. Actual supervised model charges are not priced or independently verified here; a pending receipt incurs no model invocation, and this trigger grants no new billing/API authority. An operator must observe and record the real task outcome through the existing fixed tool.

The cursor and status files are private runtime evidence under `${PRIVATE_EVIDENCE_PATH}`; they are not a second taste store. Startup metadata races and uncertain/corrupt cursor state remain explicit safe statuses. Shutdown stops the owned clock thread; the unchanged controller still enforces the fixed runtime expiry. There is no automatic purchase, acquisition, download, playback, message, calendar write or preference update.

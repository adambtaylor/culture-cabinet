# Bounded festival readiness

Fringe uses the existing fixed public transport and normal event action. Its leaf recognizes the observed article/date fields, requires explicit source years and exact official event links, and preserves show runs separately from individual performances. It ignores images and artist hover panels, caps scanning at 48 cards and output at nine leads within eight weeks, and never follows detail pages. A past-only listing is unavailable, not a verified empty current programme. Source references follow the existing retention controls.

The fixed MIFF programme target is https://miff.com.au/program; Comedy Festival uses https://www.comedyfestival.com.au/browse-shows/. These replace homepage acquisition targets under the same source IDs and origin reservations, as specified in Architecture amendment 02D. They have no production parser yet, so normal actions remain unavailable and send no request. There is no homepage/catalogue fan-out.

On 11 November 2026 retained applicable robots rules allowed these exact programme paths with the existing ten-second minimum. One MIFF programme attempt timed out before usable HTTP. Comedy returned HTTP 200, 59,268 bytes, with no dated show cards, time fields or JSON-LD established in the returned HTML. No retry, hidden endpoint, inferred programme edition or detail fetch was attempted. The earlier MIFF homepage mixed 2026 navigation and a 2024 programme label; Comedy advertised 2027. Neither supplies actual performance dates.

The mapped Fringe index returned 20 September/October 2026 rows, all past at observation. This package adds truthful readiness and parser behavior, not a working-source or browser-acceptance claim. Fixture checks cover runs/points, invalid dates/layout, stable occurrence identity, limits, transport reservations, exact programme targets, and normal action/replay/save/respond/Undo/fresh-session behavior.

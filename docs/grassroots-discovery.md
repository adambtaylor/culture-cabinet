# Grassroots source increment

Tribe and Sound Systems of Melbourne use the existing explicit source-read
reservation, current authority recheck, 15-minute result cache, identity
reconciliation and shared rating funnel. They are not a separate recommendation
list. Reading announcements never adds enjoyment, attendance, favourites or
inferred genres. One bounded Gather current candidates action includes both
sources; each also has its own explicit read button in Music & events.

Tribe's RSS supplies up to nine announcements, preserving publication and feed
update dates separately from unknown event starts. The source's last build can
be older than a fresh retrieval, and the UI says so. Its robots policy disallows
automated iCalendar reads, so there is no detail fetch or implicit fallback.

Sound Systems supplies up to nine dated source observations inside eight weeks.
Four actual observations were normalized on 30 October 2026. A common listing
URL does not collapse separate events. Exact source date/clock wording and a
supported community description remain attributed, not promises of attendance,
public access, timezone or ticket stock. Undisclosed/TBA locations remain hidden.
Public organiser-post links are retained as references without opening social
accounts or reading those pages. Its rate-limited Google calendar was not retried.

Halftix's official All Events link is visible in both discovery and the funnel.
Its permission-required state makes no network request and supplies no copied
inventory. Discounts vary; offered price, face value, fees, stock, cutoff and
voucher/entry rules require the exact offer. Nothing is purchased.

The current source set does not establish complete psytrance/doof, day-party or
festival coverage. Triniq and canonical organisers are next research-backed
candidates. Area 3000's plain page does not expose its widget inventory; it
remains a manual/browser source. AustrAliens' public announcements do not grant
access to private gatherings or attendee-only locations. OzTrance is not a
verified active connector. No new account, private-group read or contact occurred.

This delta adds no schema or dependencies. Full existing preference, booking and
completion data remain unchanged on deployment. The already approved runtime
expiry is retained. Synthetic HTTP tests exercise cache, revocation, idempotency,
shared funnel ratings and unknown source metadata; separate live read evidence
records actual returned leads without writing user ratings.

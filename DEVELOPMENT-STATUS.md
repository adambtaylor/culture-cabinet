# Development status

This source-only snapshot is a private WIP baseline. It preserves the selected
development candidate and its known limitations. It is not a claim of working
Enhance, live inference, clean-target readiness, ordinary-user acceptance or full
product acceptance.

## Validation of this export

The bounded static pass passed: 366 Python files parsed and compiled in memory,
4 JSON files parsed, 54 HTML files consumed by the standard HTML parser, and
4 JavaScript/CommonJS files checked with an already installed Node binary.
HTML ingestion is not Django rendering or visual acceptance.

The 493-file allowlist contains 490 selected source files plus this status,
README and ignore rules. All 494 selected original files retained their hashes,
sizes and modes. Executable code and dependency pins were unchanged except for
identified display/fixture expectation strings, whose AST structure was checked
against the originals. No guard, migration or assertion was removed.

No application, database, integration, server, browser or provider tests ran.
The retained synthetic canaries and credential-URL rejection cases are not live
credentials. The bounded secret-pattern scan found no known key/private-key
shapes; it does not prove absence of every possible encoded or custom secret.

## Existing failures and limits

An earlier combined synthetic suite recorded 2,056 unique tests: 2,034 successful,
3 failures, 17 errors and 2 skips, with a nonzero exit. That run is historical
evidence, not a result for this export. Later source repairs have not established
a passing combined suite here.

Retained issue areas include reversible migration traversal, initialization of
raw database guard functions, typed and pending-recovery fixtures, restart
database/journal layout, a recovery race with incomplete exception detail, and
setup/HTTP fixture compatibility. Some compatibility repairs are present, but
their presence is not passing runtime evidence. Signing-time and Apple TV
acceptance findings also remain open; none was repaired by this export.

The source setup preview is a reusable development dependency. End-to-end
Enhance must still demonstrate selected-profile ratings/notes, available API
collection before inference, settlement across all enabled categories, grounded
For You explanations, persisted results/reactions, useful progress and partial
failures, and real browser behavior. Synthetic inference cannot substitute for
live-inference acceptance.

Live source/model consent, credentials, permitted spend, source rights, current
provider handling and runtime limits remain separate gates. No production,
deployment, network listener, live provider or household-data operation was
performed or authorized by preparing this snapshot.
